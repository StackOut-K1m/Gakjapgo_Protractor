# 시연 시나리오 — 각잡고(Protractor)

시연 순서에 따른 화면별·동작별 상세 설명입니다. (URL: `https://gakjapgo.site`)

## 시연 단계 요약

| # | 화면 | 동작 / 클릭 | 설명 |
|---|---|---|---|
| 1 | 회원가입 | 이메일 입력 → **이메일 인증** → 가입 버튼 클릭 | 이메일 인증 기반 회원가입 |
| 2 | 온보딩 | 학습 목적 · 하루 목표 시간 · 관심 분야 선택 | 여기서 받은 목표가 이후 리포트 **달성률 지표**가 됨 |
| 3 | 감지 동의 | 상단 2개 항목 **동의**(필수) + 마지막 선택 항목 | 필수 2개 미동의 시 이용 불가. 선택 항목 OFF 시 **타임랩스 미측정**(추후 수정 가능) |
| 4 | 메인 | **스터디룸 생성** 클릭 | 스터디룸 진입 |
| 5 | 자세 기준 잡기 | 바른 자세로 캘리브레이션 | 사용자별 체형·앉은 높이 기준으로 **본인 기준** 설정 |
| 5-1 | (검증) | 일부러 자세 흐트러뜨리기 | 나쁜 자세는 **기준으로 안 잡힘**(잘못된 기준 방지) |
| 6 | 공부 화면 | 공부 시작 후 자세 무너뜨리기 | 화면 옆 **신호등**: 초록(정상)/빨강(불량) |
| 6-1 | 경고 | 10초 이상 지속 불량 시 경고창 + **음성 경고** | 즉시 경고 아님(10초 지속 조건). 화면 미시청 시에도 들리게 음성 안내 |
| 6-2 | 재알림 | 턱 괴기 등 지속 시 재알림 | 고칠 때까지 경고 **누적** |
| 7 | 스트레칭(강제 전환) | 같은 부위 경고 **3회** 누적 시 자동 전환 → 동작 수행 | 웹캠으로 동작 검증: 제대로 해야 진행바 참, 대충 하면 미통과. 완료 시 자동 복귀 |
| 8 | 집중 방해 감지 | 휴대폰 사용 / 졸음(4초+) / 화면 이탈 | 휴대폰·졸음 감지(깜빡임과 구분). 다른 창은 **PiP**로 띄워도 감지 지속 |
| 9 | 학습 결과 | 공부 종료(나가기) | 집중 시간·이석 시간·바른 자세 비율·경고 횟수 + **타임랩스**(압축 영상) |
| 10 | 주간 리포트 | 리포트 열람 → **PDF 다운로드** | 요일별 학습량·집중 시간대·목/턱/어깨 부위별 점수 + **AI 개선 제안** |
| 11 | 캘린더 | 일정 관리 페이지 | 개인 일정 관리 |

## 시연 흐름 (내레이션 기준)

1. **회원가입** — 이메일 인증을 거쳐 가입.
2. **온보딩** — 왜/얼마나/어떤 분야로 공부하는지 입력. 이 목표가 리포트 달성률 지표가 됨.
3. **감지 동의** — 상단 2개 필수 동의, 마지막 선택 항목 OFF 시 타임랩스 미측정(추후 수정 가능).
4. **스터디룸 생성** 후 입장 → **내 바른 자세 캘리브레이션**. 일부러 나쁜 자세를 취하면 기준으로 잡히지 않음(잘못된 기준 방지).
5. **공부 시작 → 자세 무너뜨리기** — 신호등이 빨강으로. **10초 지속** 시 경고창 + 음성 경고. 턱 괴기 등 지속 시 재알림 누적.
6. **같은 부위 경고 3회 → 스트레칭 화면 강제 전환** — 웹캠으로 동작을 검증(대충 하면 진행바 안 참), 완료 시 공부 화면 복귀.
7. **집중 방해 감지** — 휴대폰 사용, 졸음(4초 이상), 화면 이탈(PiP로도 감지 지속).
8. **공부 종료 → 결과** — 집중/이석 시간, 바른 자세 비율, 경고 횟수, 타임랩스.
9. **주간 리포트** — 요일별·시간대·부위별 점수 + PDF 다운로드 + AI가 다음 주 개선점 제안.
10. **캘린더** — 일정 관리.

## 마무리 멘트
> 자세가 무너지는 걸 **실시간으로 잡아주고**, 악화 전에 **스트레칭으로 예방**하며, 그 기록을 **리포트로 정리**해주는 서비스입니다.
