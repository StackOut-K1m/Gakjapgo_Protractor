## 1. Google 소셜 로그인 (OAuth 2.0)

- **용도**: 구글 계정 소셜 로그인.
- **가입/발급**: Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client ID(웹 애플리케이션).
- **필요 설정**:
  - Authorized redirect URI: `https://gakjapgo.site/api/v1/auth/oauth/google/callback` (테스트: `https://i15c106.p.ssafy.io/...` 도 등록)
  - OAuth 동의 화면 구성.
- **발급 값**:
  - Client ID: `<GOOGLE_CLIENT_ID>`
  - Client Secret: `<GOOGLE_CLIENT_SECRET>`
- **동작**: 백엔드가 authorize URL 생성 → 구글 인증 → 위 redirect(백엔드 콜백) → JWT 발급 → 프론트 `OAUTH_FRONTEND_CALLBACK_URL`로 복귀.

## 2. Kakao 소셜 로그인 (OAuth 2.0)

- **용도**: 카카오 계정 소셜 로그인.
- **가입/발급**: Kakao Developers → 내 애플리케이션 → 앱 생성.
- **필요 설정**:
  - 카카오 로그인 활성화 ON.
  - Redirect URI: `https://gakjapgo.site/api/v1/auth/oauth/kakao/callback` (+ 테스트 도메인)
  - 플랫폼 → Web → 사이트 도메인: `https://gakjapgo.site`
- **발급 값**:
  - REST API 키(Client ID): `<KAKAO_CLIENT_ID>`
  - Client Secret: `<KAKAO_CLIENT_SECRET>`

## 3. GMS (SSAFY 생성형 AI 통합 시스템)

- **용도**: 주간 AI 리포트 소견 생성(LLM). OpenAI 호환 API.
- **발급**: SSAFY GMS 포털에서 팀 API 키 발급.
- **값**:
  - `GMS_API_KEY`: `<GMS_API_KEY>`
  - `GMS_BASE_URL`: `https://gms.ssafy.io/gmsapi/api.openai.com/v1`

## 4. AWS S3

- **용도**: 주간 리포트 **PDF 저장**.
- **가입/발급**: AWS IAM 사용자 생성 → 프로그래밍 액세스 키 발급 → 대상 버킷에 S3 권한 부여.
  - ⚠️ 본 서비스는 **Lightsail**이라 인스턴스 역할로 S3 접근 불가 → **IAM 유저 키 필수**.
- **값**:
  - `AWS_ACCESS_KEY_ID`: `<AWS_ACCESS_KEY_ID>`
  - `AWS_SECRET_ACCESS_KEY`: `<AWS_SECRET_ACCESS_KEY>`
  - 버킷: `gakjapgo-reports-kr` / 리전: `ap-northeast-2`
- 버킷 설정이 비어 있으면 리포트는 로컬 디스크로 폴백(ReportStorageConfig).

## 5. Gmail SMTP (메일 발송)

- **용도**: 비밀번호 찾기 시 임시 비밀번호 메일 발송.
- **발급**: Gmail 계정 2단계 인증 활성화 → **앱 비밀번호** 발급(계정 비번 아님).
- **값**:
  - `MAIL_USERNAME`: `<MAIL_USERNAME>` (운영 Gmail 계정)
  - `MAIL_PASSWORD`(앱 비밀번호): `<MAIL_PASSWORD>`
  - Host: `smtp.gmail.com`
  - (테스트 환경은 별도 Gmail 계정 사용)

## 6. Datadog (모니터링)

- **용도**: 인프라 지표·로그 수집, 백엔드 APM 트레이스, 프론트 RUM.
- **가입/발급**: Datadog(ap1 리전) → Organization Settings에서 **API Key**, RUM Applications에서 **RUM App ID/Client Token** 발급.
- **값**:
  - `DD_API_KEY`(agent): `<DD_API_KEY>`
  - `DD_SITE`: `ap1.datadoghq.com`
  - RUM `VITE_DD_RUM_APP_ID`: `3ef01d23-62f5-4dfc-90a5-a5372c318b93`
  - RUM `VITE_DD_RUM_CLIENT_TOKEN`: `pub5ab2bc6be03310368795b538a6dd1bc2` (브라우저 노출용 공개 토큰)
- **동작**: `dd-agent` 컨테이너가 docker.sock·/proc·컨테이너 로그를 수집. 백엔드는 `dd-java-agent`로 APM(→`datadog-agent:8126`), 프론트는 번들에 RUM 주입.
