# 각잡고(Protractor) 포팅 매뉴얼 — exec

이 폴더는 GitLab 소스를 클론한 뒤 서비스를 **빌드·배포·재현**하기 위한 산출물입니다.

| 파일 | 내용 |
|---|---|
| `1_빌드_배포_매뉴얼.md` | 제품·버전, 빌드 방법, 환경변수 전체, 배포 절차, 배포 특이사항, 주요 계정·프로퍼티 파일 |
| `2_외부서비스_정보.md` | 소셜 로그인·GMS·S3·메일·모니터링 등 외부 서비스 가입/활용 정보 |
| `protractor_prod_dump.sql` | 운영 DB 덤프 (전체 스키마 + **정제 시드**: 샘플 계정 admin·user1~4 + 마스터 테이블만, 그 외 데이터 제거) |
| `4_시연_시나리오.md` | 시연 순서에 따른 화면별·동작별 상세 설명 |

> 🔑 **자격증명 표기**: 문서 내 민감한 값(비밀번호·시크릿·API 키)은 보안상 `<PLACEHOLDER>` 형태로 표기했습니다.
