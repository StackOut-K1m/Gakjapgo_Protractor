# 음성 안내(TTS) — 백엔드 작업 요청

자세 경고와 스트레칭 알림을 목소리로도 읽어 주는 기능입니다.
**프론트는 다 붙였고 지금도 동작합니다.** 다만 방 설정으로는 저장되지 않습니다.

작성 기준 브랜치: `feature/pip`

---

## 무엇이 이미 되는가

읽기 자체는 **브라우저 내장 음성 합성**(Web Speech API)으로 합니다.
서버로 나가는 것이 없고, 외부 TTS 서비스도 쓰지 않습니다.

| 상황 | 읽는 문장 |
|---|---|
| 자세 확정(10초 지속) | `거북목 경고입니다. 턱을 살짝 당기고 목을 곧게 세워 바르게 앉아주세요.` |
| 임계치 직전 | 위 문장 + `한 번 더 감지되면 스트레칭이 시작됩니다.` |
| 졸음 | `졸음이 감지되었습니다. 잠시 스트레칭하거나 휴식을 취해보세요.` |
| 휴대폰 | `휴대폰이 감지되었습니다. 시야 밖에 두고 학습에 집중해주세요.` |
| 스트레칭 시작 | `거북목 경고가 5회 누적되었습니다. 스트레칭을 시작합니다. 화면의 동작을 따라 해주세요.` |
| 스트레칭 완료 | `스트레칭을 완료했습니다. 학습을 이어서 진행하세요.` |

끄고 켜는 자리는 세 곳입니다 — 방 만들기 폼, 스터디방 컨트롤바, 작은 창(PiP) 헤더.

---

## 지금 상태 — 방 설정이 아니라 **브라우저 설정**입니다

`study_rooms` 에 관련 컬럼이 없어서, 방 만들기에서 고른 값이 갈 곳이 없습니다.
그래서 지금은 이렇게 우회하고 있습니다:

```ts
// utils/voiceGuidance.ts — localStorage
'gakjapgo:voice-guidance': 'true' | 'false'
```

- 방을 만들며 고른 값 → **만든 사람의 브라우저**에 저장 → 그 사람이 방에 들어가면 그대로 시작
- 스터디방 토글로 바꾼 값 → 같은 자리에 덮어씀 → 다음 입장에도 이어짐
- **다른 참여자에게는 전달되지 않습니다.** 각자 자기 브라우저 값으로 시작합니다.

즉 "음성 안내가 켜진 방"을 만들어도, 들어오는 사람들에게는 아무 영향이 없습니다.
방장이 자기 것만 켠 셈입니다.

프론트는 이미 `voiceGuidanceEnabled` 라는 이름으로 생성 요청에 실어 보내고 있습니다.
Jackson 기본 설정이 모르는 필드를 버리기 때문에 지금은 조용히 무시됩니다.

---

## 요청 사항

### 1. `voice_guidance_enabled` 컬럼 — 있으면 좋음

`stretching_enabled` / `voice_recording_enabled` 와 성격이 같습니다.

| 위치 | 내용 |
|---|---|
| 테이블 | `study_rooms.voice_guidance_enabled BOOLEAN NOT NULL DEFAULT true` |
| 엔티티 | `StudyRoom.voiceGuidanceEnabled` |
| 생성 요청 | `CreateStudyRoomRequest.voiceGuidanceEnabled` (미지정 시 true) |
| 수정 요청 | `UpdateStudyRoomRequest.voiceGuidanceEnabled` |
| 상세 응답 | `StudyRoomResponse.voiceGuidanceEnabled` |

목록 응답에는 **안 넣어도 됩니다.** 음성 녹음과 달리 입장 전에 알아야 할 정보가 아닙니다
(들어와서 끄면 그만이고, 개인정보와도 무관합니다).

### 2. 기본값은 `true` 로 — 주의

`voice_recording_enabled` 는 기본이 `false` 였지만 이건 반대입니다.
경고를 놓치지 않게 하려고 만든 기능이라, 꺼진 채로 시작하면 있는 줄도 모르고 씁니다.
끄는 스위치가 방 안에 있으니 부담도 적습니다.

---

## 컬럼이 생기면 프론트가 할 일

지금 구조를 그대로 두면 안 되고, 아래처럼 바뀌어야 합니다. **프론트 작업이 남습니다.**

```
방 상세 응답의 voiceGuidanceEnabled  →  이 방에 들어갔을 때의 초기값
스터디방 토글                        →  이번 세션에만 적용 (방 설정을 덮어쓰지 않음)
```

`utils/voiceGuidance.ts` 의 localStorage 는 그때 **지워야 합니다.**
방 설정과 브라우저 설정이 둘 다 남아 있으면 어느 쪽이 이기는지가 애매해집니다.

## 이 문서와 같이 볼 것

- `docs/backend/voice-recording.md` — 이름이 비슷하지만 **다른 기능**입니다.
  그쪽은 스터디 중 음성을 녹음해 회의록을 만드는 것이고, 이 문서는 화면이 감지한 것을
  읽어 주는 것입니다. 컬럼 이름을 헷갈리지 않게 `recording` / `guidance` 로 갈라 두었습니다.
- `docs/backend/room-password.md` — 잠긴 방 비밀번호 검증이 없는 문제. 그쪽이 더 급합니다.
